# 仓库盘点上线核对清单

- [ ] GitHub Pages 为 main / (root)，首页显示 v0.4.2。
- [ ] 公共仓库没有原始备件 Excel、真实库存 JSON、员工导出、金额与客户信息。
- [ ] 员工手机导入当年正式库存 JSON，并在飞行模式下打开 App、搜索零件、保存测试记录。
- [ ] 一条记录：临时改箱号，点固定选项直接返回；未写完的备注仍保留。
- [ ] 临时手输重量必须按“确认手动输入”；清空重量直接生效。
- [ ] 清空带下级的箱号必须明确询问是否连带清除；取消时完整保留。
- [ ] 记录页左滑出现编辑/删除，点击删除无需弹窗，6.5 秒内可以撤销。
- [ ] 点击删除后立即导出；电脑合并新旧导出不重复计算，报告有「已删除记录」。
- [ ] 不同记录 ID 的重复盘点仍触发「重复盘点待复核」，不会自动累加。
- [ ] 正式盘库结束后每位员工导出最终 JSON，再交给电脑端汇总。
- [ ] 确认备份成功后，才清除手机数据。勿删除 PWA 或 Safari 网站数据。
